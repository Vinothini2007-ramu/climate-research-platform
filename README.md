# Climate Research & Environmental Data Hub

Full-stack implementation using React + TypeScript, Node.js + Express.js, PostgreSQL, Redis, REST API, Docker and Git/GitHub.

## Run with Docker

```bash
docker compose up --build
```

Open:
- Frontend: http://localhost:5173
- API: http://localhost:5000/api/health

Demo registration can be done from the Register page.

## Main features

- JWT authentication
- Dataset upload and metadata management
- CSV analytics and visualization
- Research project creation
- Project membership
- Redis caching for dashboard statistics
- PostgreSQL persistence
- Dockerized frontend/backend/database/Redis
- REST API
